Tab Berkas di slide verifikasi dilengkapi dengan berkas dari detail order

Sekarang tab Berkas di slide cuma punya File PO, Surat Kesanggupan Bayar, dan Bukti Pembayaran. Di detail order masih ada Surat Masuk Permohonan, Proposal Riset / Teknis, dan Surat Penawaran Harga. Ketiganya disalin ke sini (ditandai biru BARU khusus di demo ini, di aplikasi tandanya tidak ada). Klik "Lihat file" untuk coba pratinjau.
